# P07 candidate checks

Extract the entire ZIP and launch `Overload.exe`. Keep its `.pck` and runtime folder. Existing characters migrate without losing XP or gear. The earlier S06 independent session remains open; its [feedback form](S06_FIRST_PLAYTEST.md) is included.

At Hearth, **Create separate Standard character** starts a level-1 character with no synthetic wallets and preserves existing profile files. The eight-room court opens the Fracture board. The accelerated sandbox is still labeled and cannot use the earned ritual. For a separate inspection profile, `Overload.exe -- --fracture-practice=10` opens the E05 authored proving ground; return to its board to inspect the new activities without changing a normal save.

1. Select a region and Hunt, Breach or Vault. Check the displayed tier, laws, target loot and reward budget. Vault requires reaching the golden keystone after guardians die. All activities currently use the court art kit.
2. Clear a group, return to Hearth, quit and resume. The same generated layout and next checkpoint should return. Retry restores supplies without paying twice.
3. At tier 10+, verify six Seals and the region/family proof on completion. Completing the third family adds a one-time twelve-Seal bonus. Check the regional journal for mastery requirements.
4. Earn Stillness by remaining within 0.25m for 0.8s and landing a base hit; earn Rupture by causing a base stagger break. Overloaded hits should not refresh either. Unlock Focused through Hollow mastery, Shatter through Crown mastery and Cascade through the trial, then compare their tradeoffs.
5. Try the Trial of Contradiction with Override disabled. Land two different Assault skills/signatures in stage one, follow the safe lane in stage two, and defeat the boss. Compare the character's exact XP, gear and ranks before and after. Failure consumes no materials. The temporary power is disclosed before entry.
6. On a qualified Standard character, commit the earned ritual once and reload. It should consume 120 of each region's Seals and retain Elsewhere ownership. A missing requirement must block payment.
7. Choose an Anomaly mutation. Check its tell and escape route: return mark, wider/slower fan, longer preparation or lateral movement. Try every disclosed rule pair with ordinary Traverse and Elsewhere.
8. Start a chain. Complete leg one, reload, then continue. Death forfeits only the current leg's optional wallet bonus. Extract early and check that all prior rewards remain. Successful legs two/three add 10%/20% of that leg's ordinary gold/Alloy, with no bonus XP or Seals.
9. Defeat the Remembering Sovereign. Check the anchor halo, Codex entry and personal record; it must not waive the ritual or add numerical power. Inspect records with standard/assisted labels.

Record input device, build label, region/family/tier, reproduction steps, deaths, completion time, unreadable hits, navigation failures, and why you continued or stopped. No human duration, enjoyment or difficulty result has been recorded yet.
