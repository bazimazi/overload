# E05 candidate: manual checks

Extract the entire Windows ZIP and run `Overload.exe`. Keep the `.pck` and runtime directory with it. Start the saved court normally; completing its eight rooms opens **Fracture board and attunement** at Hearth. Normal characters keep their existing equipment, XP and wallets through save migration.

The S06 independent playtest is still pending. Its [original feedback protocol](S06_FIRST_PLAYTEST.md) remains useful for controls and comprehension. This candidate adds progression work at the owner's explicit request, without claiming the previous human gate has passed.

For an accelerated tier check, run from the extracted directory:

```powershell
.\Overload.exe -- --fracture-practice=9
.\Overload.exe -- --fracture-practice=10
.\Overload.exe -- --fracture-practice=11
```

Each command creates a new isolated sandbox profile at the tier's suggested level with shared grade one below it. Your ordinary save is unchanged. These are seven-group expeditions using authored court rooms, not full production activity families. They award no regional proofs or Seals.

Check the following and send observations with input device, build label, room/tier and reproduction steps:

1. Compare damage and survivability across 9, 10 and 11. Record time, deaths, obvious unfair hits and useful build changes.
2. Clear a group, visit Hearth, quit and resume. Check XP and the next group; retry should restore supplies without paying a second reward.
3. Complete the expedition. Confirm exact total XP and wallet payouts, next-tier access, and an earned grade at the forge. Buying it should deduct both displayed costs once.
4. At tier 10 completion, inspect the three saved chapter routes, quit before choosing and return. Choices must remain identical. Pick a route and inspect its targeted drop.
5. Try a previously unlocked low tier. Its XP and enemies should stay fixed even after leveling up; it should not advance the frontier again.
6. Compare balanced, offense, defense and manual Resonance allocation. Check the exact ledger and free respec; record any missing or negative points.

Full bags forfeit Fracture targeted drops; the board discloses this. Current route choices change target family and authored room assembly. World rules, boss mutations, real production oath qualification and three-leg chains remain later work. No human balance, duration or enjoyment results have been recorded yet.
